# 起卦插圖

抽牌儀式最前面那一段 —— 水晶球浮上來、光暈在背後綻開、兩隻手從左右合圍、
球亮起來炸出一把星屑 —— 吃這裡的插圖。

| 檔名 | 內容 | 要求 |
| --- | --- | --- |
| `orb.webp` | 水晶球（含底座） | 去背，直立 |
| `aura.webp` | 放射狀的光暈／能量 | 去背；**原圖可以是白底**，用下面的工具轉 |
| `hand-l.webp` | 從左下伸上來的手 | 去背，手腕在下、指尖朝上，畫面是長條的 |
| `hand-r.webp` | 從右下伸上來的手 | **選配** —— 沒有的話右手直接拿左手鏡射 |

## 怎麼放進來

原圖丟進一個資料夾，檔名叫 `orb` / `aura` / `hand-l` / `hand-r`
（png、jpg、webp 都可以），然後：

```bash
python3 tools/make_ceremony.py 你的資料夾
```

工具會縮圖、壓成 WebP，並且**把光暈那張的白底轉成透明**。
白底不能靠 CSS 混色拿掉（`screen` 讓黑變透明，白的永遠是白的；
`multiply` 讓白變透明，但整張會跟著變暗），所以在這一步一次做掉：
把「離白有多遠」當成 alpha，顏色再除回去 —— 等於把 multiply 合成反推回來。
轉完的圖在 CSS 裡用 `mix-blend-mode: screen` 疊加，
透明處不動，有顏色的地方會把底下的夜空點亮而不是蓋掉，星星還看得見。

## 為什麼缺圖不會出事

`orb` / `aura` / `hand-l` 少任何一張，**整段起卦就跳過**，
抽牌直接從聚牌開始（見 `src/tarotdraw.js` 的 `loadArt()`）——
少一段特效沒關係，卡在黑畫面不行。

這幾張也**不進 Service Worker 的安裝外殼**：`cache.addAll()` 只要有一個 404
就會讓整個 Service Worker 裝不起來。改成第一次用到才抓，
存在跟版號無關的 `xj-art` 快取裡，改版不用重抓。

單張建議壓到 150 KB 以內。

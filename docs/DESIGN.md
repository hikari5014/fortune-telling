# 玄鑑 XUAN JIAN — 設計規劃書

一個離線可用的 PWA 命理工具箱。本機算得出來的（曆法、星盤、紫微、姓名格局、數字磁場）一律本機算；
需要「解讀」的部分不內建模型，改為**產生提示詞 → 貼到外部 LLM → 把結果貼回來存檔**。

---

## 1. 產品定位

| 項目 | 決定 |
|---|---|
| 形態 | PWA（可安裝、離線可用、無後端） |
| 技術 | 原生 ES Modules + CSS，零建置、零相依套件 |
| 資料 | 全部存在裝置 localStorage，可匯出／匯入 JSON |
| 隱私 | 不上傳任何資料；只有使用者自己複製提示詞出去 |
| 語言 | 繁體中文為主，提示詞可切語言 |

## 2. 資訊架構

```
首頁 Home          今日概況 · 快速入口 · 最近紀錄
 └ 檔案 Profile    多組出生資料（自己／家人／朋友），可切換當前對象
 ├ 星盤 Astro      太陽 / 月亮 / 上升 / 中天 / 生肖 / 四柱八字 / 節氣
 ├ 紫微 Ziwei      十二宮盤、十四主星、六吉六煞、五行局、身命宮
 ├ 姓名 Naming     五格三才、81 靈動數、取名筆畫推薦
 ├ 數字 Numbers    數字磁場、車牌／手機評分、幸運數字、雙方匹配
 ├ 提示 Prompt     提示詞產生器（模板 + 自由編輯 + 資料注入）
 ├ 紀錄 Records    貼回來的 LLM 解讀，依對象／類別歸檔
 └ 設定 Settings   外觀 / 動態 / 命理參數 / 提示詞預設 / 資料管理
```

導覽：手機底部 Tab（5 主項 + 更多），桌機左側 Rail。左右滑動可切換主分頁。

## 3. 計算引擎（全部本機）

### 3.1 曆法 `engines/calendar.js`
- 儒略日 ⇄ 西曆
- 太陽黃經（VSOP 簡化，誤差 < 0.01°）→ **二十四節氣即時求解**
- 月相朔望（Meeus 第 49 章）→ **定朔定氣農曆**（初一＝朔日、無中氣置閏）
- 四柱：年柱以「立春」為界、月柱以「節」為界、日柱用儒略日 `(JDN+49)%60`、時柱用五鼠遁
- 納音五行（六十甲子完整表）

### 3.2 星盤 `engines/astro.js`
- 太陽黃經 → 星座（回歸黃道）
- 月亮黃經（ELP 主要項，誤差 < 0.3°）→ 月亮星座
- 恆星時 → **上升星座（Asc）與中天（MC）**，需經緯度，公式：
  `Asc = atan2(cos(RAMC), −(sin(RAMC)·cosε + tanφ·sinε))`
- 真太陽時校正（經度時差＋均時差）可於設定開關

### 3.3 紫微斗數 `engines/ziwei.js`
- 農曆生日 + 時辰 → 命宮／身宮
- 命宮干支（五虎遁）→ 納音 → 五行局（水二／木三／金四／土五／火六）
- 起紫微訣定紫微，再排紫微系 6 星、天府系 8 星
- 祿存、擎羊、陀羅、天魁、天鉞、文昌、文曲、左輔、右弼、地空、地劫、火星、鈴星
- 十二宮：命、兄弟、夫妻、子女、財帛、疾厄、遷移、交友、官祿、田宅、福德、父母

### 3.4 姓名學 `engines/naming.js`
- 康熙筆畫字典（內建常用字）＋**單字手動修正**＋不確定時可用提示詞去問 LLM
- 五格：天格／人格／地格／外格／總格（單姓單名補一規則可於設定切換）
- 三才配置（天人地 → 五行生剋）
- 81 靈動數完整吉凶表
- 取名推薦：給姓氏筆畫，窮舉名字筆畫組合並依五格＋三才評分排序

### 3.5 數字 `engines/numbers.js`
- 八星數字磁場：天醫／生氣／延年／伏位／絕命／五鬼／六煞／禍害
- 手機、車牌：兩兩拆解計分＋總和 81 數吉凶
- 生命靈數（含主числ／天賦數）
- 幸運數字推薦、兩組號碼／兩人匹配度

> 所有結果一律標示「推算方式」與「僅供參考」。

## 4. 提示詞產生器（核心差異點）

設計原則：**夠自由**。

1. **資料積木**：每個引擎算完的結果都註冊成一個「資料區塊」，使用者勾選要帶哪些進提示詞。
2. **模板**：內建多種（深度命盤解讀、流年、感情、事業、取名建議、號碼挑選、自由問答…），
   全部可複製成自訂模板編輯。
3. **變數系統**：`{{name}} {{bazi}} {{ziwei_table}} {{naming}} {{numbers}} {{question}} {{today}} …`
   點一下就插入；未知變數原樣保留，不會壞掉。
4. **輸出控制**：角色設定、語氣、深度、長度、輸出格式（條列／表格／Markdown／JSON）、語言、是否要免責聲明。
5. **完全自由模式**：空白編輯器 + 變數面板，等於一個小型 prompt IDE。
6. **一鍵複製 → 外部 LLM → 貼回**：貼回的文字存成紀錄，附帶當時的模板與資料快照。

## 5. 視覺與動態

- **黑白主題**：純單色系統（白底黑字 / 黑底白字 / 跟隨系統）。層次靠灰階、細線、網點、留白。
- **字體（Google Fonts）**：
  - 標題 `Noto Serif TC`（明體的骨感，對應命理感）
  - 內文 `Noto Sans TC`
  - 數字 `Space Grotesk`
- **圖示**：全部自繪 SVG 線條圖示，**不使用 emoji**。App icon 為幾何星盤。
- **動態交互（基本設計條件，觸控與滑鼠都要成立）**
  - 過場：View Transitions API，不支援時退回 CSS 關鍵影格
  - 進場：IntersectionObserver 逐項 stagger
  - 觸控：左右滑動切頁、長按選單、拖曳選號、下拉關閉 sheet
  - 指標：卡片跟隨游標的光暈（`--mx/--my`）、磁吸按鈕
  - 回饋：按壓縮放 + 漣漪 + 震動（可關）
  - 數值：count-up 動畫、環形進度描邊動畫
  - 尊重 `prefers-reduced-motion`，並在設定提供「關閉／輕量／完整」三段

## 6. 設定頁（統整所有參數）

外觀｜主題、字級、對比、圓角
動態｜動畫強度、過場效果、觸覺回饋、滑動切頁
命理｜時區、出生地（經緯度／城市）、真太陽時、早晚子時換日、姓名學流派、外格規則
提示詞｜預設語言、語氣、長度、格式、免責聲明、自訂前綴／後綴
資料｜匯出、匯入、清除、快取版本、安裝 App
